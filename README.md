# BlockCred AI

### AI-Powered Blockchain-Based Universal Certificate Verification and Fraud Detection Platform

BlockCred AI is a real-world recruiter-grade platform designed to automatically parse, audit, and verify certificates during hiring, admissions, employee onboarding, background checks, and credential validation.

---

## Key Features

1. **OCR Extraction:** Automated parser extracting Candidate Name, ID, Course, Issue Date, and URLs. Utilizes Google Cloud Vision with a local Tesseract fallback.
2. **Blockchain Registry:** Immuted records written to Ethereum smart contracts via University MetaMask wallets.
3. **AI Visual Forensics:** Powered by Google Gemini to identify visual edits, pixel anomalies, text alignments, fake signatures, and metadata manipulation.
4. **QR Decoders:** Auto-scans QR codes to extract validation links and cross-reference records.
5. **Dashboard Portals:** Tailored user screens for Super Admins, University Authorities, Recruiters, Students, and Verification Officers.
6. **PWA Integration:** Completely responsive, mobile-optimized, and installable on Android and iOS devices with camera access.

---

## Tech Stack

* **Frontend:** React, TypeScript, Tailwind CSS, Vite (PWA)
* **Backend:** FastAPI, Python, PyMuPDF, OpenCV, ReportLab (PDF Reports)
* **Database & Auth:** Firebase Firestore, Firebase Authentication
* **Blockchain:** Ethereum, Solidity, Ganache/Hardhat, Ethers.js v6

## System Requirements

### 1. Tesseract OCR (For Fallback OCR)
* **Windows:** Download the installer from UB Mannheim Tesseract page and install. Add the installation folder (default: `C:\Program Files\Tesseract-OCR`) to your system environment Path.
* **Mac:** Run `brew install tesseract`
* **Linux:** Run `sudo apt-get install tesseract-ocr`

### 2. MetaMask Extension
* Install the MetaMask extension in your browser to sign University credential registrations.

## Local Setup & Installation

### Step 1: Clone or Open Workspace
Open this directory in your IDE or shell:
```bash
C:\Users\Dell\.gemini\antigravity-ide\scratch\blockcred-ai
```

### Step 2: Environment Configuration
Copy the `.env.example` file to `.env` and configure your credentials:
```bash
cp .env.example .env
```
*Fill in your `GEMINI_API_KEY` to enable Gemini AI forensics.*

### Step 3: Compile and Launch Blockchain Contract (Hardhat)
To run a local blockchain node and compile:
1. Open a terminal in the `blockchain/` folder:
   ```bash
   npm install
   ```
2. Launch the local Hardhat Node (simulates Ganache network on port 8545):
   ```bash
   npx hardhat node
   ```
3. Deploy the smart contract in a separate terminal:
   ```bash
   npx hardhat run scripts/deploy.js --network localhost
   ```
   *Note: This will deploy the contract and print the contract address. Copy it into your `.env` file under `CONTRACT_ADDRESS`.*

## Remix IDE Support

If you prefer to compile and deploy using Remix IDE:
1. Copy the contract code from `blockchain/contracts/CertificateVerification.sol` and paste it into a file named `CertificateVerification.sol` in Remix.
2. Under **Solidity Compiler**, select compiler version `0.8.20` or higher and click **Compile**.
3. Under **Deploy & Run Transactions**, select **Injected Provider - MetaMask** or **Dev - Ganache Provider**.
4. Click **Deploy**.
5. Once deployed, copy the Contract Address and compile-built ABI and paste them into your config files if customizing address paths.

## MetaMask Configuration

To connect MetaMask to your local blockchain network (Hardhat/Ganache):
1. Open MetaMask, click the Network dropdown, and select **Add Network** -> **Add a network manually**.
2. Input the following details:
   - **Network Name:** Hardhat Local
   - **New RPC URL:** `http://127.0.0.1:8545`
   - **Chain ID:** `31337` (or `5777` for Ganache GUI)
   - **Currency Symbol:** ETH
3. Click **Save**.
4. Import one of the private keys generated by your `npx hardhat node` shell output to get test accounts pre-funded with 10,000 ETH.

## Running the Applications

### Run FastAPI Backend
1. Create a python virtual environment inside `backend/` and install requirements:
   ```bash
   cd backend
   python -m venv venv
   .\venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Start the FastAPI server:
   ```bash
   python app/main.py
   ```
   *The Swagger interactive API documentation will be available at: http://127.0.0.1:8000/docs*

### Run React Frontend (Vite)
1. Open a terminal in the `frontend/` folder:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
2. Open http://localhost:3000 in your browser.

## Docker Execution (Production / Test Build)

To spin up all services together (FastAPI server + React frontend static serve) using Docker Compose, run:
```bash
docker-compose up --build
```
The console will be accessible on port 3000, and backend APIs will be bound to port 8000.
